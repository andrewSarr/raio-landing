La fondation est prête. Les rails vous appartiennent.

raio livre la fondation ; les couches au-dessus appartiennent à la communauté. La direction est des rails de paiement instantané africains, interopérables entre fournisseurs et frontières. Voici les prochaines étapes à plus forte valeur — choisissez-en une, ouvrez une issue avec le modèle « Implement a missing crate », et lancez-vous.

M1
Un LedgerStore durable
Livré : raio-ledger-redb (pur Rust). Des backends SQL/Postgres sur le même point d'extension sont bienvenus.
Livré
M2
Un KeyDirectory durable
Livré : raio-dict-redb (pur Rust). Des backends SQL/Postgres sur le même point d'extension sont bienvenus.
Livré
M3
Le codec QR interopérable
Livré : raio-qr — EMVCo Merchant-Presented Mode, le standard mondial utilisé par les fournisseurs mobile money africains, aux côtés du raio-brcode pour Pix.
Livré
M4
Un trait Transport + livraison exactement-une-fois
Le point d'extension de messagerie entre participants — messagerie ISO 20022 + adaptateurs GSMA Mobile Money derrière un seul trait synchrone.
Aide bienvenue
M5
raio-rail
La chambre de compensation HTTP + les nœuds participants — demande de paiement → résolution de clé → règlement → émission QR/BR Code, entre nœuds.
Bonne première crate
M6
Un adaptateur SettlementProvider de production
Adaptateurs PAPSS / RTGS / mobile money — remplacer l'exemple naïf par quelque chose de réel.
Aide bienvenue
M7
SDK + CLI opérateur
L'expérience développeur au-dessus des rails.
Aide bienvenue
